# G.Y Fly 🚀

> 种一棵树最好的时间是十年前，其次就是现在。

基于 VitePress 构建的个人技术博客，专注于前端技术分享与学习笔记整理。

## 📖 项目简介

这是一个使用 VitePress 搭建的个人技术网站，包含了丰富的前端学习资源、课程笔记、面试题库和技术文章。网站支持中英文双语，提供了完整的前端技术栈学习路径。

- **框架学习**: Vue3、React、TypeScript 深度解析
- **工程化**: Webpack、Vite、前端工程化实践
- **性能优化**: 前端性能优化策略与实战

## 🚀 快速开始

### 环境要求
- Node.js >= 16
- pnpm >= 8

### 安装依赖
```bash
pnpm install
```

### 本地开发
```bash
pnpm run docs:dev
```

### 构建部署
```bash
pnpm run docs:build
```

### 预览构建结果
```bash
pnpm run docs:preview
```
